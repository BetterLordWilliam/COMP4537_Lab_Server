Section 4: Virtual Machine Provisioning and Deploying Node Server

Now to discuss the provisioning of a FREE virtual machine from Oracle and how the application which has been developed can be deployed to it.

4.1 Obtaining an Oracle Cloud Machine

The first step along this journey is to create an oracle cloud account.

Assuming that this is already done, here are the steps to acquire a VM

  1. Sign into Oracle Cloud
  2. Click the hamburger in the top left
  3. Click compute
  4. Click instances
  5. Click create instance
  6. Give the instance a name
  7. Choose the Ubuntu image, whatever the LTS is
  8. Choose the shape of the instance, VM.Standard.E2.Micro is always free, but you can use VM.Standard.A1.Flex with 4 CPUs and 24GB or RAM for free
  9. Click next until you get to the network screen
  10. In the SSH keys section, save the generated private and public key
  11. Continue clicking next leaving settings at their default values
  12. Click Create
official oracle docs

4.2 SSH Into the Machine

Once the machine is provisioned and finishes creating, the next step is to gain access via SSH

The following instructions assume that you have downloaded SSH keys to the machine that you have provisioned in the previous section.

  1. Open a shell on your machine
  2. Navigate to the directory where you downloaded the SSH key to
  3. Run the following commands

    4. PowerShell 
    ssh -i $myprivatekeypath "ubuntu@$mymachinepublicip"
    Bash 
    ssh -i $myprivatekeypath "ubuntu@${mymachinepublicip}"

  4. If you are using the correct private key and the public IP address of you machine is correct, you will be granted access to the machine

4.3 Installing Node and Npm + UFW Config

Now that a machine has been provisioned and you have access to it over SSH, you can install NodeJS and npm

  1. SSH into the machine
  2. Install NodeJS
  3. Install npm

    4. Bash 
    sudo apt update
sudo apt install nodejs -y

# verify
node -v
npm -v

  4. Intall git

    5. Bash 
    sudo apt install git -y
git --version

  5. Use git to clone the repo with the node server you have built
  6. Don't forget to install your node dependencies

    7. Bash 
    npm i
  7. In addition to installing all the dependencies, you will need to configure Ubuntu ufw

    8. ufw == uncomplicated firewall

  8. Enable SSH through ufw

    9. Bash 
    sudo ufw allow ssh

  9. Enable access to your server port through ufw

    10. Bash 
    sudo ufw allow YOUR_PORT_NUMBER/tcp

  10. Enable the ufw

    11. Bash 
    sudo ufw enable

official oracle docs

4.4 Internet Traffic Ingress to The Server

The final step, allow internet to access your node server

  1. Click on your instance
  2. Goto networking tab
  3. Create VNIC or click it if it already exists
  4. Goto VNIC subnet, then the security tab of the VNIC subnet
  5. Add a security list or edit the default security list
  6. Goto security rules page
  7. Click Add Ingress Rules
  8. Specify the source as the internet 0.0.0.0/0
  9. TCP PROTOCOL
  10. Destination port as your server port, 6767 for example

BEWARE, the internet now will have access to your machine. I hope that these collection of guides were either useful & informative or funny.
