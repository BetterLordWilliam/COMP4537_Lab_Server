USE BCRYPT WITH NODE FOR HASHING, IT IS THE GOAT 🐐🐐🐐

bcrypt npm

bcrypt package faciliates salting, hashing and then comparing strings against their hashed counterparts (example, verifying a users password matches hashed version).

cool bcrypt facts
  • SALT IS CONTAINED, don't need to come up with your own salt, you get premium himilayan pink salt
  • compare() function to compare incoming values against hashed ones, very nifty

Also, a useful package for JWT is jsonwebtoken from npm, quite lovely.

faciliates creating JWTs with information (like the users email address or id so they can be used to identity) and with configurable expire times.

cool jsonwebtoken facts
  • jwt are encoded as base64url and then signed, which ensures the authenticity of the token (ie, some goober cannot modify the state of the token)
  • stateless authentication, meaning that the server doesn't need to track or store session information -- as the guy writing the authentication server for term project, this is a real nice bonus!
  • three parts of a JWT, header, payload, signature
  • widely used, so this is a good thing to know
  • bummer, cannot easily revoke a jwt, it will be valid for its lifetime. Common solution is to give a token two life times, access and refresh tokens, access with shorter lifetimes, and refresh with longer lifetimes -- these of course are used to generate new access tokens.
